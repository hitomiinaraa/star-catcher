A tiny browser game built from one prompt:

> "Build a tiny browser game where you catch falling stars with a basket"

Bounty: [The agent builds a game from one prompt](https://make.fun/bounty/post-x-the-agent-builds-a-game-from-20261122-1709) — $20, on make.fun.

## How to run

```sh
node main.ts
```

Then open http://localhost:8080/ in your browser.

`main.ts` writes a self-contained `index.html` (the whole game, no external dependencies, no network calls) into the same directory and starts a static HTTP server on port 8080. Press Ctrl-C to stop.

## How to play

- Move the basket left and right to catch the falling stars.
- Catch a star: **+10 points**. Catch a rare golden star: **+25 points**.
- Miss a star (it hits the ground): **lose 1 life**. You have 3 lives.
- Stars fall faster as your score rises.
- Game over shows your final score — press **R** or click to play again.

## Controls

| Input | Action |
| --- | --- |
| Arrow keys / A, D | Move basket |
| Mouse move | Move basket |
| Touch drag | Move basket |
| Space / click | Start / restart |
| R | Restart after game over |

## Demo mode

Open http://localhost:8080/?autoplay=1 and the basket plays itself, tracking the nearest falling star — handy for recordings. The game engine runs normally; only the input is automated.
